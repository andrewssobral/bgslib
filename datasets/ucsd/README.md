# UCSD Sample Datasets

This directory contains a small subset of sample sequences used for foreground segmentation and background subtraction evaluation.

The original datasets were obtained from the Statistical Visual Computing Laboratory (SVCL) at the University of California, San Diego (UCSD):

http://www.svcl.ucsd.edu/projects/

## Contents

The following sample sequences are included:

- `boats/` — boat detection sequence.
- `freeway/` — highway traffic sequence.
- `peds/` — pedestrian detection sequence.

Each sequence contains:

- `frames/` — input images.
- `groundtruth/` — corresponding ground-truth masks.

## Purpose

These files are provided solely as small example datasets for testing and demonstrating the functionality of BGS Library.

For the complete datasets and additional information, please visit the original UCSD/SVCL project pages:

http://www.svcl.ucsd.edu/projects/
